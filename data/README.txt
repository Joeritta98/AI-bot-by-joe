Folder ini disediakan untuk menyimpan hasil generate.

Nota: Oleh kerana website ini ialah static site (HTML/CSS/JS untuk Netlify),
pelayar tidak boleh menulis fail terus ke folder ini. Hasil generate akan:
1. Dipaparkan terus di bahagian "Hasil Generate" dalam website.
2. Boleh dimuat turun dengan butang "Muat Turun Hasil" (masuk ke folder Downloads).
3. Direkodkan dalam galeri "Hasil Saya" (localStorage pelayar).

Jika anda mahu simpanan automatik ke server, anda perlukan backend (bukan static hosting).
